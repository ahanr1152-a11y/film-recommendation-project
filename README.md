A simple and responsive movie search application built using HTML, CSS, and JavaScript. Users can search for their favorite movies and instantly get detailed information including posters, ratings, release dates, genres, and plot summaries through API integration.
##Features
🔍 Search movies by title
🎬 Display movie posters
⭐ Show ratings and reviews
📅 View release dates
📝 Read movie plots and details
📱 Responsive design for different devices
##Technologies Used
HTML5
CSS3
JavaScript (ES6)
Fetch API
Movie Database API (OMDb API)
##Learning Outcomes
API Integration
DOM Manipulation
Asynchronous JavaScript
Responsive Web Design
Error Handling
